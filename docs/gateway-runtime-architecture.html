gateway-runtime · Architecture

Reusable Go gateway runtime — Edge routing, browser security boundary, specialized gateway roles และ replaceable providers

Security Boundary

  • OIDC Authorization Code + PKCE
  • Opaque browser session cookie
  • OAuth/OIDC tokens remain server-side
  • CSRF, rate limit และ security headers

Runtime Model

  • หนึ่ง binary/container รองรับหลาย roles
  • Production แยก deployment ตาม workload family
  • Capabilities เปิดใช้งานอย่าง explicit
  • Provider-backed operations fail closed

Shared State

  • Redis รองรับหลาย REBFF replicas
  • แยก SessionStore และ TokenStore
  • One-time OIDC flow state
  • User-context cache ไม่ใช่ source of truth

Data-plane Rule

  • Static frontend bypasses REBFF
  • Bulk object payload ส่งตรงไป storage
  • Streaming payload ผ่าน CDN/origin
  • WebSocket role ถือ long-lived connection
