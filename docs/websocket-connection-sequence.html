WebSocket Connection Sequence

อนุญาต WebSocket เฉพาะผู้ใช้ที่ authenticated และมี role ที่กำหนด เท่านั้น ผู้ใช้ที่ไม่มี session ถูกปฏิเสธใน control path และจะไม่ได้รับ connection ticket หรือเข้าสู่ WebSocket upgrade

PROPOSED · NOT IMPLEMENTED

Mandatory gate

  • Authenticated session ต้อง valid
  • ผู้ใช้ต้องมี allowed WebSocket role
  • Domain API ต้องอนุญาต channel/action
  • ทุกเงื่อนไขต้องผ่านก่อนออก connection ticket

Fail-closed behavior

  • ไม่มี/หมดอายุ session → 401
  • ไม่มี role หรือ Domain deny → 403
  • session/ticket store unavailable → 503
  • ไม่มี anonymous fallback และ reject direct upgrade ก่อน 101

Decisions required before implementation

  • ชื่อ required role และ mapping ไปยัง permission
  • ticket carrier, TTL, atomic replay protection และ audit correlation
  • role/session revoke, per-message re-check และ re-auth ระหว่าง connection
  • connection, publish/subscribe และ rate limits ต่อ user/tenant
