REBFF · OIDC Login Sequence

ลำดับการเข้าสู่ระบบด้วย Authorization Code + PKCE ตั้งแต่ Browser เริ่ม Login จนได้รับ opaque session cookie และอ่าน User Context ผ่าน /api/me

Gateway Runtime · REBFF Role
Browser SessionProduction ใช้ __Host-bff_session; Local HTTP ใช้ bff_session
Server-side StateFlow, session และ token สามารถเก็บใน Redis เพื่อใช้ร่วมกันระหว่างหลาย replica
Identity Boundaryรหัสผ่าน, MFA และ SSO ถูกจัดการโดย Identity Provider ไม่ผ่าน REBFF
Security ControlsPKCE S256, one-time state, nonce และ ID Token verification ป้องกัน callback/replay attacks
